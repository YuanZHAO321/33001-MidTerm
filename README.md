# 测验速查（30 Oct 2026 13:00–15:00，范围 XRD / ICP / SEM-EPMA）

> 题型：约 20 题，计算 / 填空 / 图片标注 / 简答。2 小时，机考，Williamson 2.45。

## A. 常数与单位
| | |
|---|---|
| h = 6.626×10⁻³⁴ J·s | c = 3×10⁸ m/s（精确 2.998×10⁸） |
| 1 eV = 1.6022×10⁻¹⁹ J | mₑ = 9×10⁻³¹ kg，e = 1.6×10⁻¹⁹ C |
| 1 Å = 10⁻¹⁰ m = 0.1 nm | 1 wt% = 10⁴ ppm；1 ppm = 10³ ppb = 10⁶ ppt |
| 主量 > 1 wt%；次量 0.1–1；微量 < 0.1 wt% | 1 kV 加速电压 → 电子获得 1 keV |

## B. 公式
| 公式 | 用途 |
|---|---|
| E = hν；λν = c；**E = hc/λ** | 能量/频率/波长互换；**E(keV) ≈ 12.4/λ(Å)**；E(eV) ≈ 1240/λ(nm) |
| k = 1/λ | 波数 |
| ½mv² = eV → v = √(2eV/m) | 电子速度 |
| n = c_air / c_medium，**频率不变** | 介质中波长 λ_m = λ_air / n |
| a·sinθ = mλ | 单缝衍射暗纹 |
| **nλ = t·sinα** | 光栅（ICP-OES 分光、DVD、水波槽） |
| **nλ = 2d·sinθ** | 布拉格定律（XRD；EPMA 的 WDS） |
| C′_unk = C_std·I_unk/I_std；C_unk = C′_unk·F_unk/F_std；F = F_Z·F_A·F_F | EPMA 定量 / ZAF |
| U = E₀/E_C（最佳 2–3） | 过电压 |
| R = 0.0276·A·E^1.67/(ρ·Z^0.89) μm | 相互作用体积（趋势：E↑R↑，Z↑R↓） |
| %An = Ca/(Ca+Na)；%Fo = Mg/(Mg+Fe) | 端元比例（用 apfu） |

### 计算易错点
- XRD 图横轴是 **2θ** → 先 **除以 2** 得 θ；Excel 的 SIN 用 **弧度**（RADIANS()）。
- J ↔ eV ↔ keV、Å ↔ m ↔ nm 换算别漏数量级。
- 校准曲线先看 **哪个轴是浓度**；误差通常给 **±3σ**；R² > 0.95（practical 判据）。
- 分子式计算：斜长石按 **8 O**、橄榄石按 **4 O** 归一；阳离子/氧比：SiO₂ ½、TiO₂ ½、Al₂O₃ ⅔、Cr₂O₃ ⅔、FeO/MgO/CaO/MnO 1、Na₂O/K₂O 2、P₂O₅ 0.4。

## D. 对比
- **轫致辐射**（连续、背景）vs **特征 X 射线**（元素指纹）
- **单晶 XRD**（要旋转样品）vs **粉末 XRD**（随机取向，不用旋转）
- **角度色散**（单色光、扫角度，实验室）vs **能量色散**（白光、固定角，同步辐射）
- **OES**（激发 → 光 → 光谱干扰，Si 好）vs **MS**（电离 → m/z → 质量干扰，Si 差）
- **单色器**（一次一元素）vs **多色器**（Rowland 圆，同时多元素）
- **SE**（形貌，与 Z 无关）vs **BSE**（成分，随 Z 增亮）
- **EDS**（快、全谱、定性）vs **WDS**（慢、单元素、定量；靠布拉格衍射）
- **精密度**（重复性）vs **准确度**（接近真值）

## E. 干扰例子
- ICP-OES 光谱：Pb 220.353 nm 在 Al 220.467 nm 肩上；Mg 2852 Å / As 2860 Å；V / Fe 3111 Å
- ICP-MS 质量：同质异位 ⁴⁰K/⁴⁰Ca、⁵⁸Fe/⁵⁸Ni；多原子 ⁴⁰Ar³⁵Cl⁺ → ⁷⁵As⁺；双电荷 ⁸⁸Sr²⁺ → ⁴⁴Ca⁺
- EDS：MoS₂ 中 Mo Lα 2.293 / S Kα 2.307 keV；Si Kα / Rb Lα；O Kα / Cr Lα
- ICP 测不了：卤素（OES）、CHON、惰性气体；MS 原则上只测不了 F、Ne、He（电离能高于 Ar）
